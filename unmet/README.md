# Unmet

`/unmet` — pick a country, see which of twelve basic needs are met for everyone, which are closing, and the year the rest arrive at today's pace. Drawn on Buckminster Fuller's Dymaxion map.

Links carry the state: `/unmet?c=COD` opens a country, `&n=electricity` one need, and `&vs=RWA` compares it with a second country (the first is drawn in gold, the second in white).

It is a standalone document, like the games: the Angular app never imports it, so it adds nothing to the Angular bundle. `angular.json` copies `unmet/dist` into the site as static files.

## Commands

| Command | What it does |
| --- | --- |
| `npm run unmet:data` | Fetches the twelve indicators from the World Bank into `unmet/data/unmet.json`. Needs internet. Commit the result. |
| `npm run unmet:build` | Builds `unmet/dist`. Runs as part of `npm run build`. Fetches the data first if there is none. |
| `node unmet/scripts/build.mjs --dev` | Same build, but falls back to sample data with a warning when there is no snapshot. `npm start` uses this so local work never blocks. |
| `npm run unmet:dev` | Preview at http://localhost:5176/unmet/ with rebuild on save. Add `-- --sample` to use invented data. |
| `npm run test:unmet` | Unit tests for the labels, the pace arithmetic and the fetch script. |

There is nothing to install. The build uses the esbuild that Angular already brings in; the page itself has no run-time dependencies.

## First run

```sh
npm run unmet:data     # once, then commit unmet/data/unmet.json
npm run unmet:dev
```

Until `unmet/data/unmet.json` exists, the only data is `unmet/data/sample.json`, which is **invented**. The page shows a banner when it loads sample data, and `npm run build` refuses to ship it.

Refresh the data whenever you like by running `npm run unmet:data` again. The World Bank updates most of these series once or twice a year.

## How it stays fast

- The first paint needs the HTML (all CSS is inlined), one script of about 23 KiB gzipped, `map.json` and a 34 KiB file of land dots (12 KiB on phones). The globe draws from those.
- Dot positions on the Dymaxion map, the data and the fonts load while the globe turns.
- A country's outline is fetched only when that country is chosen.
- Nothing calls an API while a visitor waits. The one exception is typing a city name, which asks Open-Meteo's geocoder; country search works without it.
- Everything except `index.html` has a content hash in its path and can be cached forever (see the `/unmet/...` headers in `firebase.json`).

## Layout

```
unmet/
  index.html          page template (the build fills in the %PLACEHOLDERS%)
  src/
    needs.js          the twelve needs: indicator code, goal, and why that goal
    model.js          the reasoning: met / closing / not closing / not measured, pace, peers
    map.js            canvas: globe, the unfold, the Dymaxion map, zoom, picking
    panel.js          HTML for the country panel, one need, the pace strip, "How this works"
    i18n.js           every word, in English and French
    main.js           state, URL, search, wiring
    styles.css
  scripts/
    fetch-data.mjs    World Bank API -> data/unmet.json
    build.mjs         -> dist/
    dev.mjs           preview server
    build-geo.mjs     pre-computes data/geo (see below)
    make-sample-data.mjs
  data/
    unmet.json        the real snapshot (created by unmet:data)
    sample.json       invented numbers for development
    countries-ref.json  ISO codes, names, capitals
    geo/              generated: dots, outlines, the unfolded icosahedron
  public/fonts/       Instrument Serif, DM Sans, DM Mono (SIL Open Font License)
  test/
```

## Changing what is measured

Edit `src/needs.js`. Each need names a World Bank indicator, the level that counts as "met", and a key into the `why` text in `src/i18n.js` that explains where the level comes from. Add the need's wording to both languages in `src/i18n.js`, then run `npm run unmet:data`. If an indicator is retired, the fetch skips it and the page shows the needs that loaded.

## The map data

`data/geo` is generated by `node unmet/scripts/build-geo.mjs` from `src/assets/maps/countries-50m.json`, using the `d3-geo-polygon` Fuller projection already in the repo. It takes about 30 seconds and only needs re-running if the country shapes or dot counts change. Land is sampled on an even (Fibonacci) lattice over the sphere, so every dot stands for the same area; each dot is stored with its position on the unfolded map and the country it belongs to. That is why the page needs no map library at run time.

## Before launch

- The page has `<meta name="robots" content="noindex, follow">`. Remove it in `index.html` when you want it indexed, and add `/unmet` to `src/sitemap.xml`.
- The goals in `src/needs.js` are editorial choices. Two (internet, financial account) have no formal international target and say so on the page. Have Medard review the table in "How this works".
- "The Fuller Projection Map design is a trademark of the Buckminster Fuller Institute" appears in "How this works". Check what the Institute asks of you for this use.
